# Original AhMatTaYa preset instrumentals

These three short, procedurally composed and synthesized loops are created for this project. They contain no third-party recordings, samples or copied melodies. They are instrumental sketches, not recordings of commercial songs.

- `little-celebration.wav`: bright bell/keys, 104 BPM, 18.46 seconds.
- `soft-promise.wav`: gentle keys, 76 BPM, 25.26 seconds.
- `memory-evening.wav`: calm arpeggio, 68 BPM, 28.24 seconds.

To the extent possible under law, copyright and related rights in these generated assets are waived. No attribution is required. This dedication applies to these generated presets, not third-party libraries or other repository assets.

Regenerate with `python3 scripts/generate-music.py`. Output is 22,050 Hz, mono, 16-bit PCM WAV. WAV is used for broad browser support without a platform encoder dependency; total size is about 3.1 MB. Players use `preload="none"`, so tracks are requested only when played. Small encoded delivery variants can be introduced later without changing stored track IDs.
